02 / A NUMERICAL STOP, NOT AN EXACT CERTIFICATE
Two variables move. One equality stays.
The dual uses 0 ≤ α ≤ C and yᵀα = 0. Each pair follows a feasible line segment and maximizes its one-dimensional quadratic, including the zero-curvature endpoint case. This is a deterministic max-violation pair rule, not a reproduction of every Platt heuristic.

04 / CONTROLS THAT BREAK EASY CLAIMS
Accuracy can hide unfinished optimization.
Duplicate inputs can have different optimal dual-support allocations with the same decision function. A support-vector coefficient is not unique causal data importance. These supplied mathematical controls are not causal ablations of the historical dataset.
