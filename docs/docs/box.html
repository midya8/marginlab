03 / WHY THE BOUND IS ATTAINABLE
Each coordinate has a sign.
For f(x) = c + a·x, a positive coefficient takes its minimum at the lower input endpoint and its maximum at the upper endpoint. A negative coefficient reverses that choice. Zero coefficients are free. Summing these independent coordinate extrema gives both exact bounds and corners that attain them. This is the established support-function calculation for a box, not a new robustness method.
Native Python Fraction and an independent browser BigInt implementation check the complete witness, every coordinate support equality and the tie-aware reachable labels. Tiny cases are also checked by exhaustive corner enumeration. Four source-bound affine declarations and 128 full responses are reproduced offline, without refitting or changing the original scores.
Validity is not authenticity. A proof about a changed affine function can be internally valid. This page separately recomputes weights from every saved support coefficient and represented standardized training input, then checks mean and scale rescaling against the declared affine function. That match is local consistency, not a security boundary or authentication.
